# AI Usage Report

## 1. Tools Used and Use Cases

### ChatGPT

ChatGPT was the only AI tool used during this assignment. I used it as a learning and development assistant rather than copying its output without review.

ChatGPT assisted me with:

- Breaking the assignment requirements into smaller steps.
- Planning the project folder and file structure.
- Explaining HTML, CSS, JavaScript, Git, and GitHub.
- Explaining how to write a README file using Markdown.
- Reviewing the semantic structure of the HTML page.
- Explaining responsive design and CSS media queries.
- Suggesting and reviewing CSS for my chosen color palette.
- Generating JavaScript dark-mode button.
- Identifying spelling, grammar, and code-quality issues.
- Reviewing the project against the assignment requirements.
- Creating original SVG illustrations for the two projects.
- Organizing and improving the project documentation.

Some examples of questions and requests I gave ChatGPT included:

- What information must be included in the README?
- Is GitHub Desktop required if I use IntelliJ IDEA?
- What does a CSS media query do?
- Is a media query required?
- How can I implement a dark and light theme?
- Does my HTML, CSS, and JavaScript meet the assignment requirements?

## 2. Benefits and Challenges

### Benefits

ChatGPT made unfamiliar web-development concepts easier to understand. It helped me divide the assignment into manageable stages instead of trying to complete the entire website at once.

The explanations of Markdown, semantic HTML, responsive design, CSS Grid, media queries, and JavaScript event handling were useful while I was learning.

AI assistance also helped me review the project. It identified issues such as remaining placeholder text, grammar mistakes, unclear image alternative text, and inconsistent capitalization.

### Challenges and Limitations

Some AI responses contained more detail than I needed as a beginner. ChatGPT also suggested optional features that were not required by the assignment, which could have increased the workload unnecessarily.

For example, it suggested adding an additional contact-form interaction even though the dark-mode toggle already satisfied the JavaScript requirement.

I therefore had to compare each suggestion with the assignment instructions and decide whether it was necessary and appropriate for the assignment.

## 3. Learning Outcomes

Through this assignment and the use of AI assistance, I learned:

- How HTML provides the structure of a webpage.
- How CSS controls colors, spacing, layout, and responsiveness.
- How JavaScript responds to a button click and changes the page theme.
- How CSS Grid displays project cards in columns.
- How a media query changes the layout at different screen widths.
- How semantic HTML elements organize a webpage.
- How form labels, input types, required fields, and image alternative text improve usability.
- How Markdown is used to create GitHub documentation.
- How a clear folder structure separates content, styling, scripts, images, and documentation.
- Why AI-generated suggestions still require human review and testing.

## 4. Responsible Use and Modifications

I reviewed AI suggestions before including them in the project. I asked for explanations when I did not understand a concept and simplified suggestions that were too detailed for the assignment.

I personalized the suggestions by:

- Writing the About Me content using my own background and goals.
- Describing my selected projects.
- Selecting the website color palette.
- Requesting a simpler CSS solution that I could understand.
- Correcting and revising the project descriptions.
- Choosing dark mode as the JavaScript feature.
- Reviewing the generated SVG illustrations.
- Adding meaningful alternative text to the images.
- Testing the website in Safari using a mobile-sized browser window.
- Rejecting optional features that were outside the required scope.

The final decisions about the website structure, content, colors, and features were mine. AI was used transparently as a learning and review tool.
